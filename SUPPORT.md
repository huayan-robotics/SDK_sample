# Support and issue reporting

[简体中文](SUPPORT.zh-CN.md)

This repository is maintained from the Huayan Robotics internal Sample source. External code contributions and pull requests are not used as the maintenance path. Code and documentation changes are reviewed, implemented, and synchronized by the internal team.

Customers and SDK users are welcome to report reproducible problems and request sample improvements through GitHub Issues. A maintainer will review the report and determine the internal handling and release plan.

## Before opening an issue

- Search existing issues first to avoid duplicate reports.
- Select the bug report or sample request form instead of opening a blank issue.
- For a problem, state the product, programming language, SDK version, operating system, and compiler or runtime.
- Include the exact command, return code, reproduction steps, expected result, actual result, and a minimal relevant log.
- For a sample request, explain the customer scenario, affected products and languages, and the observable success result.
- Do not include customer data, credentials, private network addresses, or confidential files.

## Pull requests

External pull requests are not accepted. A pull request may be closed with a request to describe the problem or proposal in an Issue instead. This policy keeps the public repository aligned with the internally verified source and release process.

## Security issues

Do not report a security vulnerability in a public Issue. Follow [SECURITY.md](SECURITY.md).
