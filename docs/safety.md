# Safety

[简体中文](zh-CN/safety.md)

Some samples command real robot motion or continuous control.

Before running a sample:

- verify that the repository project matches the physical robot;
- confirm the controller mode and SDK compatibility;
- check the robot IP and all local parameters;
- validate the home position in the actual workspace;
- use conservative speed and force settings during initial testing;
- keep the emergency stop available;
- keep personnel and obstacles outside the robot workspace.

Default values in sample code are examples and must not be treated as verified settings for every site.
